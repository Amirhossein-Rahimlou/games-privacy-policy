## Adding a game

1. Copy `rush-street/` to a new folder named after the game (lowercase, dashes).
2. Edit the title, texts, dates and partner list.
3. Add a theme in `assets/style.css` (copy `.theme-rush-street`, change the two colours) and set it on `<body>`.
4. Add a card for the game in `index.html`.

All pages share `assets/style.css` (light and dark mode) and `assets/toc.js` (highlights the current section).
